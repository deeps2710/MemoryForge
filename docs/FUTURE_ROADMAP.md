# Gated roadmap

Phase 1: deterministic CPU ML engine, evaluation, conflict mechanism, tests and
evidence ledger. See PHASE_STATUS.md for verified status.

Phase 2, only on explicit instruction: Streamlit guided preset, live teach/query,
real matrix and score visualizations, visible encoder/memory deltas, shots
control, conflict, clear, accessibility, learner check, latency and UI tests.

Phase 3, only on explicit instruction after Phase 2: verify 3+ recent primary
papers, integrate a sourced BDH learning module, run varying-shot/seed/corruption
evidence with real charts, write technical walkthrough and broaden robustness.

Phase 4, only on explicit instruction after Phase 3: final README, license and
AI disclosure audit, one-page concept summary PDF, resolve blog-PDF ambiguity,
deploy public artifact, verify access, demo script, rubric and submission audit.
The actual organizer PDF/portal must be checked; the current development brief
is the only supplied source of competition rules.

Post-hackathon candidates (planning only): Omniglot/Fashion-MNIST/CIFAR embeddings;
modern Hopfield memories; learned update rules; attention comparisons; meta-learning
and prototypes; consolidation/continual learning; capacity/interference studies;
larger models; GPU support; packaged library. Do not implement before the
competition-critical phases are complete. Preserve the narrow central claim.

Status update 2026-09-07: Phases 1–3 are implemented and verified. Phase 4 remains
gated to the next explicit instruction; post-hackathon extensions remain deferred.
